1. while loop:
                - Runs only when the condition is true.
                - must update the value inside the loop 
                 - if the condition never becomes false, it becomes an infinite loop.

    syntax:
             while(condition)
             {
                //code
             }
    Example:
              
   let i =1;

   while(i <= 5)
   {
    console.log(i);
    i++;
   }
------------------------------------------------
2. do..while
  
        - the code runs at least one time before checking the condition
        - after running once,it checks the condition.
        - continues as long as the condition is true.
    syntax:

    do{
        //code
    }
    while(condition);

example:
     let j =1;
do 
{
    console.log(j);
    j++;
}

while(j <= 5);

3. for
        - Used to repeat something a fixed number of times.
        - it runs from a start value to an  end value.
        - the value changes every loop(incease or decrease) 

syntax:
        for(inilize; condition;increment/decrement)
        {
            //code
        }
Example:
          for(let i =1; i<=5; i++)
            {
             console.log(i);
              }
---------------------------------------------------------------------------------------
4. for...of
           - Used to get each value from an array.
           - gives values directly without index.
           - very simple and clean to work.

syntax:
         for(let value of array)
         {
            //code 
         }
      
 Examples:
 let fruits = ["apple", "mango", "banana"];

for(let f of fruits)
{
    console.log(f);
}

//-------------------------------------------------
   const fname ="harish";
