3.promise chaining
                   Used for step-by-step work (instead of callback hell)
                  Promise Chaining is a method where multiple asynchronous tasks run one after another, in a proper sequence.
Each .then() waits for the previous Promise to finish (resolve) before starting the next one.

✔ Ensures ordered execution
✔ Removes callback hell
✔ Makes async code clean and readable
✔ Works step-by-step (sequential workflow)

Syntax:
         promise1()
  .then(promise2)
  .then(promise3)
  .then(promise4)
  .catch(errorHandler);
Where We Use Promise Chaining?

We use Promise chaining when tasks must run in a specific order, like:

Login → then fetch user → then fetch posts

Load data step-by-step

Complex async workflows

Database operations in order

Animations one after another

Backend processes that depend on previous steps

API calls that must run sequentially

5prototype:
            Prototype is a hidden parent object that all JavaScript objects have.

If an object does NOT have a property/method,
JavaScript will automatically search in its prototype.

👉 Prototype = Parent
👉 Object = Child
👉 Child uses parent’s properties through prototype

6.What is Inheritance? (Very Simple Notes)

Inheritance means one object can use another object's properties and methods.

JavaScript uses prototype to do inheritance.

Example:
Student inherits Person.
Car inherits Vehicle.
